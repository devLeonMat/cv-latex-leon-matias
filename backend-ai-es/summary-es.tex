\section{Resumen Profesional}

{\small
Ingeniero Backend con \textbf{más de 12 años de experiencia} en arquitectura y desarrollo de
sistemas cloud-native, REST APIs y microservicios distribuidos con \textbf{Java, Spring Boot y
Node.js/NestJS} en los sectores de Salud, Banca, Seguros, Servicios Financieros y Logística.

\vspace{4pt}
Especializado en \textbf{orquestación de agentes IA y diseño de flujos agénticos} — con experiencia
directa en la arquitectura de una plataforma empresarial de agentes IA (\textbf{AgentCloud}), que
integra LLMs, buses de eventos con Kafka e infraestructura AWS para clientes Healthcare en
Estados Unidos. Practicante de desarrollo backend asistido por IA (Claude Code, GitHub Copilot,
Cursor) para scaffolding, revisiones de código e ingeniería de prompts.

\vspace{4pt}
Amplia experiencia en programación reactiva (\textbf{Spring WebFlux}), arquitecturas event-driven
(\textbf{Apache Kafka}), autenticación bancaria (\textbf{Spring Security}) y despliegues cloud en
\textbf{AWS, Azure y GCP}. Historial probado integrando backends Java y Node.js con sistemas
críticos de Scotiabank, SambaSafety, Banco GNB Paraguay, Equifax, BCP y RIMAC.
}
